# Siddharth Pandey — Portfolio

A static, responsive portfolio website built with HTML, CSS, and JavaScript for deployment through GitHub Pages.

## Local preview

```bash
python3 -m http.server 8002
```

Then open `http://localhost:8002`.

## GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, then select the `main` branch and `/(root)` folder.
